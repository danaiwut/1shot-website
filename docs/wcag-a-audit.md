# UI Audit: แดชบอร์ด 1SHOT ตามเกณฑ์ WCAG 2.2 Level A

ขอบเขต: ทุกหน้าใต้ `src/app/(app)` (สมาชิก 8 หน้า และแอดมิน 9 หน้า) รวมโครงหน้า (sidebar, top bar, เมนูมือถือ)
ไม่รวม: หน้า landing, `/pricing`, `/login`, `/signup`

สถานะ: ✅ แก้แล้ว · ⚪ ผ่านอยู่แล้ว / ไม่เกี่ยวข้อง · ⚠️ ยังต้องตรวจเพิ่ม

## แก้เพิ่มนอกเหนือ Level A (เกณฑ์ AA)

- **1.4.3 Contrast**: สี `faint` เดิม `#8c8c8c` บนพื้นขาวได้ 3.4:1 และ `#6e6e6e` บนพื้นดำได้ 4.1:1 ซึ่งไม่ผ่าน จึงเปลี่ยนเป็น `#6b6b6b` (5.3:1) และ `#8f8f8f` (6.4:1)
- **2.4.7 Focus Visible**: กรอบโฟกัสใช้สี `accent` จึงเห็นชัดทั้งบนพื้นขาวและพื้นดำ (สีแดงแบรนด์เดิมบนพื้นดำได้แค่ 2.9:1)

## สิ่งที่เปลี่ยนในเลย์เอาต์

- **โครงหน้า**: sidebar แบ่งกลุ่ม "เมนู" และ "ผู้ดูแลระบบ" มีหัวข้อกำกับ · desktop มี top bar แสดงตำแหน่งปัจจุบัน (breadcrumb), เวลาไทย และปุ่ม "ซื้อ / ต่ออายุ"
- **PageHeader**: หัวข้อใหญ่ขึ้น และมีเส้นคั่นใต้หัวข้อ
- **ภาพรวม**: การ์ด "ตั้งค่าบัญชี" ย้ายขึ้นไปเป็นแถบด้านบนพร้อม progress bar, ขั้นตอน 3 ช่อง และปุ่ม "ทำขั้นตอนถัดไป" (ซ่อนเมื่อทำครบ) · ช่องตัวเลขที่ 3 เปลี่ยนเป็น "ใกล้หมดอายุ (7 วัน)" · สิทธิ์ที่ใกล้หมดมีป้าย "ใกล้หมด"
- **สัญญาณ**: รวมตัวกรองไว้ในกล่องเดียวพร้อมป้าย "สถานะ" และ "ฝั่ง"

## ⚠️ ยังต้องตรวจเพิ่ม

- ยังไม่ได้ทดสอบใน browser และกับ screen reader จริง (VoiceOver / NVDA) ในรอบนี้ ที่ตรวจแล้วคือ typecheck, unit test, ทุกหน้าโหลดได้ (HTTP 200) และสแกน HTML ไม่พบช่องกรอก ปุ่ม หรือลิงก์ที่ไม่มีชื่อ
- สีเขียว `buy` `#0a8a5f` บนพื้นขาวได้ประมาณ 4.4:1 ซึ่งต่ำกว่าเกณฑ์ AA สำหรับตัวอักษรขนาดเล็กเล็กน้อย
- ยังไม่ได้ตรวจหน้า landing, pricing, login และ signup
